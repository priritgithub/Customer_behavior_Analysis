## How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook to perform EDA and data cleaning.
5. Import the cleaned dataset into MySQL.
6. Execute the SQL queries.
7. Open the Power BI (`.pbix`) file to explore the dashboard.
8. Review the project report for detailed findings.
